# Open Source

## Purpose

Parametron is an open-source software project.

This document records the project's current and long-term open-source intent. It
is not a software license, legal agreement, or governance instrument.

It describes a project principle rather than a product roadmap, commercial
plan, or commitment to specific future products.

---

## Open-Source Intent

Parametron software is developed as open-source software and is intended to
remain open source as the project grows.

The project is intended to evolve without making its software proprietary or
source-unavailable.

The possible future establishment of a company or other commercial organization
around Parametron does not change this intent.

---

## Current Public Software

The current public Parametron engineering software consists of:

- **Parametron Engine** (`parametron-engine`)
- **Parametron FreeCAD** (`parametron-freecad`)

Both are distributed under the **GNU Affero General Public License v3.0
(AGPL-3.0)**.

The applicable `LICENSE` file in each repository is authoritative for the legal
terms governing that software.

---

## Future Software

As Parametron evolves, software published as part of the project is intended to
remain open source under licenses appropriate to each project.

This intent does not prescribe a particular license for software that does not
yet exist.

It also does not define future products, repositories, architectures, delivery
models, or commercial offerings.

---

## Scope

This document expresses the Parametron project's open-source intent.

It does not:

- replace or modify the license of any repository;
- grant rights beyond those provided by an applicable software license;
- require every Parametron repository to use the same license;
- define the license of software that does not yet exist;
- require internal planning, strategy, research, commercial information, or
  other non-software material to be public;
- define future products or product architecture;
- define commercial models;
- define the governance or ownership structure of any future organization.

Repository `LICENSE` files remain authoritative for licensing terms.

---

## Principle

Parametron may grow, its software may evolve, and a commercial organization may
eventually be established around the project.

The intention remains the same: **Parametron software stays open source.**
